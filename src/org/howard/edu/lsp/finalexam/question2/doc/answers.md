The Template Method pattern is used in the abstract Report class. The generateReport() method is declared final and defines the fixed workflow: loadData() → formatHeader() → formatBody() → formatFooter(). Each step is an abstract method that subclasses must implement. StudentReport and CourseReport each override these methods to provide their own data and formatting. The Driver stores both in a List<Report> and calls generateReport() on each, demonstrating polymorphism, the right subclass methods run automatically at runtime.
