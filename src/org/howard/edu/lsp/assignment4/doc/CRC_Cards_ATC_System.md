CRC Cards — ATC System

Assignment 4

⸻

CRC Card

Class: TransponderPacket

Responsibilities:
•	Hold raw data received from a plane’s transponder
•	Store flight information (ID, type, altitude, position, speed)
•	Provide access to stored values when needed

Collaborators:
•	GroundReceiver

Assumptions:
•	Each packet represents data from one aircraft at a specific moment.

⸻

CRC Card

Class: GroundReceiver

Responsibilities:
•	Listen for aircraft broadcasts
•	Convert incoming signals into TransponderPacket objects
•	Send packet information to the database

Collaborators:
•	TransponderPacket
•	AircraftDatabase

Assumptions:
•	The receiver can hear all aircraft within airport range.

⸻

CRC Card

Class: Aircraft

Responsibilities:
•	Represent a single aircraft being tracked
•	Store current flight data (ID, altitude, speed, heading, position)
•	Update information when new packet data arrives
•	Provide aircraft details when requested

Collaborators:
•	TransponderPacket
•	AircraftDatabase

Assumptions:
•	Flight ID uniquely identifies each aircraft.

⸻

CRC Card

Class: AircraftDatabase

Responsibilities:
•	Maintain the list of aircraft currently being tracked
•	Add aircraft when they first appear
•	Update aircraft records using new packet data
•	Return aircraft information for display, safety checks, or queries

Collaborators:
•	Aircraft
•	GroundReceiver
•	DisplayController
•	SafetyAnalyzer
•	QueryHandler

Assumptions:
•	Only aircraft currently within the monitored airspace are stored.

⸻

CRC Card

Class: DisplayController

Responsibilities:
•	Refresh the controller display every 10 seconds
•	Get aircraft information from the database
•	Send updated display data to the radar screen

Collaborators:
•	AircraftDatabase
•	RadarScreen
•	AlertNotifier

Assumptions:
•	The display refresh interval is fixed at 10 seconds.

⸻

CRC Card

Class: RadarScreen

Responsibilities:
•	Show aircraft positions on the screen
•	Display flight labels for each aircraft
•	Highlight aircraft that have safety alerts
•	Update the screen when new display data arrives

Collaborators:
•	DisplayController
•	AlertNotifier

Assumptions:
•	Controllers monitor aircraft primarily through this screen.

⸻

CRC Card

Class: SafetyAnalyzer

Responsibilities:
•	Check aircraft data for unsafe conditions
•	Detect when aircraft are too close together
•	Detect possible runway conflicts
•	Create alerts when a dangerous situation occurs

Collaborators:
•	AircraftDatabase
•	Aircraft
•	SafetyAlert
•	AlertNotifier

Assumptions:
•	Minimum safe distance between aircraft is predefined.

⸻

CRC Card

Class: SafetyAlert

Responsibilities:
•	Represent a warning generated by the system
•	Store the type of alert and affected aircraft
•	Provide alert details to the display system

Collaborators:
•	SafetyAnalyzer
•	AlertNotifier

Assumptions:
•	Each alert refers to one specific safety condition.

⸻

CRC Card

Class: AlertNotifier

Responsibilities:
•	Receive alerts from the safety analyzer
•	Notify the display controller when alerts occur
•	Keep track of active alerts
•	Remove alerts when conditions are resolved

Collaborators:
•	SafetyAlert
•	DisplayController
•	RadarScreen

Assumptions:
•	Resolved alerts are removed once the condition is no longer detected.

⸻

CRC Card

Class: QueryHandler

Responsibilities:
•	Process controller requests for aircraft information
•	Look up aircraft records in the database
•	Return requested information to the terminal

Collaborators:
•	ControllerTerminal
•	AircraftDatabase
•	Aircraft

Assumptions:
•	Queries are based on flight ID selected by the controller.

⸻

CRC Card

Class: ControllerTerminal

Responsibilities:
•	Allow the air traffic controller to interact with the system
•	Accept flight ID queries
•	Display detailed aircraft information returned by the system

Collaborators:
•	QueryHandler
•	RadarScreen

Assumptions:
•	One controller operates the terminal at a time.
